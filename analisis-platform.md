# ANALISIS KOMPARATIF PLATFORM

## Pemrograman Berbasis Platform

### 1. Pendahuluan

Platform pengembangan perangkat lunak dibagi menjadi tiga jenis,
yaitu Web, Desktop, dan Mobile. Ketiganya memiliki karakteristik,
teknologi, keunggulan, dan keterbatasan yang berbeda.

### 2. Analisis Komparatif Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript | Java, C#, C++ | Kotlin, Java, Swift |
| Arsitektur | Client-server | Aplikasi pada sistem operasi komputer | Aplikasi pada sistem operasi mobile |
| Cara distribusi | Browser dan internet | Installer atau toko aplikasi | Google Play Store atau App Store |
| Keunggulan | Mudah diakses melalui browser | Integrasi dengan komputer | Praktis dan portabel |
| Keterbatasan | Bergantung pada browser dan koneksi untuk layanan online | Perlu penyesuaian dengan sistem operasi | Terbatas oleh baterai dan ukuran layar |
| Contoh aplikasi | Gmail | Microsoft Word | WhatsApp |
